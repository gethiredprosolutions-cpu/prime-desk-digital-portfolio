# PrimeDesk Digital

The official portfolio for PrimeDesk Digital.

## Development

Run `npm ci` to install dependencies and `npm run dev` to start the development server. Run `npm run build` to generate the production site in `dist`.

## Vercel

Connect this repository to the Vercel project for `primedigitalsolutions.vercel.app` and set the production branch to `main`. Vercel uses the repository root and builds the site with the settings in `vercel.json`.
